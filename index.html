    For the team: stimuli and settings
    

      
Saturation is a soft-clip curve y = tanh(d·x) / tanh(d), applied to the peak-normalised mix. d = 0 means no saturation. Both versions are then set to the same loudness (K-weighted, ITU-R BS.1770 filters, no gating) and A/B is randomised per trial. The default sound is a synthesised pop loop so the demo works offline; load your own unmastered mix to try real material.
